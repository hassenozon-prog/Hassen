# المصادر الشرعية والفقهية

يُستخدم هذا القسم للمصادر الشرعية والفقهية التي تساعد في فهم الأحكام والقواعد القانونية اليمنية عند الحاجة.

## ترتيب الاستدلال
1. القرآن الكريم والسنة الصحيحة.
2. القواعد الفقهية والأصولية ذات الصلة.
3. أقوال المذاهب الفقهية ومراجعها المعتمدة.
4. الشروح والدراسات الفقهية والقانونية.

## ضابط
لا يُقدَّم الرأي الفقهي على النص القانوني النافذ عند وصف الحكم الوضعي، وإنما يُفصل بين الحكم الشرعي والتحليل القانوني.
