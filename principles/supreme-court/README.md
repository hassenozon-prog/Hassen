# مبادئ المحكمة العليا اليمنية

## مصدر القاعدة القضائية
يختص المكتب الفني بالمحكمة العليا باستخلاص القواعد القضائية التي تقرها المحكمة العليا في قراراتها وأحكامها بعد عرضها على رئيس الدائرة التي أصدرتها، ونشر مجموعات القرارات والأحكام مصنفة ومبوبة مع خلاصة المبادئ بعد عرضها على الدائرة المختصة. 

## قاعدة التوثيق
لا يُنشأ سجل لمبدأ قضائي إلا إذا أمكن تحديد الحكم أو القرار الذي صدر عنه، ورقم الحكم أو القرار وتاريخه والدائرة ومصدر النشر.

## مستويات السجل
1. نص الحكم أو القرار.
2. خلاصة المبدأ كما وردت في مصدر قضائي.
3. المسألة القانونية التي عالجها الحكم.
4. النصوص القانونية المرتبطة.
5. تحليل الباحث — ويجب فصله عن المبدأ المنسوب للمحكمة.

## تنبيه
الملاحظات الفقهية أو التحليلية ليست مبادئ قضائية ما لم تنسب إلى حكم أو قرار محدد قابل للتحقق.
