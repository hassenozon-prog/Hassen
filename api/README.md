# API — المساعد القانوني اليمني المتخصص

واجهة HTTP بسيطة بلا مكتبات خارجية تجمع محرك الاسترجاع وطبقة الاستدلال.

## التشغيل

من جذر المستودع:

    python -m api.app

افتراضياً تستمع الواجهة على:
- HOST=127.0.0.1
- PORT=8080

يمكن تغييرهما بمتغيرات البيئة.

## endpoints

### GET /health

يعيد حالة الخدمة وعدد المقاطع المفهرسة.

### POST /query

مثال الطلب:

    {
      "question": "هل يجوز بناء الحكم على دليل لم يطرح في الجلسة؟",
      "facts": [],
      "requested_relief": "سبب طعن بالنقض",
      "limit": 8
    }

الاستجابة تتضمن:
- نتائج الاسترجاع.
- المصادر وحالة التحقق والنفاذ.
- context.
- نوع المسألة.
- القواعد المدعومة.
- التحذيرات.

لا تحتوي الخدمة على مفاتيح أو أسرار، ولا ينبغي وضع أي سر في المستودع.
