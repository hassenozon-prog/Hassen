# API — المساعد القانوني اليمني المتخصص

واجهة HTTP بسيطة بلا مكتبات خارجية تجمع محرك الاسترجاع وطبقات التحقق والاستدلال والصياغة.

## تشغيل محلي آمن

من جذر المستودع:

    python -m api.app

افتراضيًا تستمع الخدمة على `127.0.0.1:8080`. افحصها عبر `GET http://127.0.0.1:8080/health`.

## تشغيل داخل Docker أو على واجهة شبكة

إذا أردت الاستماع على عنوان غير محلي، يجب ضبط `API_KEY` أولًا. لا تستخدم القيمة الافتراضية أو تضع المفتاح في المستودع أو في سجلات الطرفية.

    export API_KEY="$(python -c 'import secrets; print(secrets.token_urlsafe(32))')"
    HOST=0.0.0.0 PORT=8080 python -m api.app

مع Docker:

    docker build -t yemeni-legal-assistant .
    docker run --rm -p 8080:8080 -e API_KEY="$API_KEY" yemeni-legal-assistant

طلبات `POST /query` و`POST /case` تتطلب:

    Authorization: Bearer <API_KEY>

يبقى `GET /health` متاحًا دون مفتاح لقياس سلامة الخدمة، ولا يعرض نصوص القضايا.

## نقاط النهاية

- `GET /health`: حالة الخدمة وعدد المقاطع المفهرسة.
- `POST /query`: استعلام قانوني؛ يتطلب `question` غير فارغ. الحقل `limit` عدد صحيح من 1 إلى 20، والحد الأقصى لحجم جسم الطلب مليون بايت.
- `POST /case`: تحليل منظم لبيانات القضية، مع متطلبات المصادقة نفسها.

مثال محلي:

    curl -X POST http://127.0.0.1:8080/query \
      -H 'Content-Type: application/json' \
      -d '{"question":"المادة 499 منازعة تنفيذ","limit":8}'

مثال عند تفعيل المفتاح:

    curl -X POST http://127.0.0.1:8080/query \
      -H 'Content-Type: application/json' \
      -H "Authorization: Bearer $API_KEY" \
      -d '{"question":"المادة 499 منازعة تنفيذ","limit":8}'

## حدود الاعتماد

- لا تنشئ الخدمة حكمًا قانونيًا نهائيًا؛ يلزم مراجعة المحامي للنصوص والوقائع والتعديلات.
- لا يجوز اعتبار نص نافذًا لمجرد وجوده في المستودع أو لأنه يحمل وصف `verified`; يجب أن تجتاز بياناته بوابة الدليل القابل للتتبع.
- لا توجد قاعدة بيانات قضايا دائمة أو إدارة مستخدمين أو تحديد معدل طلبات متقدم في هذه النسخة. للنشر العام استخدم TLS وreverse proxy مع تحديد معدل الطلبات ومراقبة آمنة، ولا تعرض الخدمة مباشرة للإنترنت دون هذه الضوابط.


## الفهرسة المتجددة والتكامل مع ChatGPT
يعاد بناء الفهرس قبل كل استعلام قانوني، ويشمل ملفات CSV في نسخة المستودع الحالية. هذا لا يجلب التغييرات الجديدة من GitHub بذاته؛ يجب تحديث نسخة العمل أو نشر إصدار جديد عند تحديث المستودع.

لربط GPT/مشروع ChatGPT بواجهة API عن بُعد:
1. انشر API على عنوان HTTPS عام خلف reverse proxy وTLS وتحديد معدل الطلبات.
2. حدّث `servers[0].url` في `api/openapi.json` إلى عنوان النشر الفعلي.
3. اضبط المصادقة في إعدادات GPT Action ولا تضع مفتاحًا ثابتًا في المستودع.
4. أضف الأكشن إلى GPT الذي تستخدمه في محادثة «نبراس القانون» ثم اختبر `GET /health` و`POST /query`.
