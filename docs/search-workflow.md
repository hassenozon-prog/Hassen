# سير عمل البحث القانوني

1. تحديد المسألة القانونية.
2. البحث في فهرس التشريعات.
3. استرجاع المادة الأصلية وحالة تعديلها.
4. البحث عن المبادئ القضائية المرتبطة.
5. مطابقة الوقائع بالأدلة.
6. فصل الثابت عن الادعاء والتحليل.
7. صياغة النتيجة مع بيان المصادر ودرجة التحقق.
8. عند نقص المصدر: التصريح بالحاجة إلى تحقق وعدم التخمين.
