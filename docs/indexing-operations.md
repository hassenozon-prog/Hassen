# تشغيل الفهرسة والتحقق منها

## إعادة بناء الفهارس محليًا

    python tools/rebuild_indexes.py --write

يعيد الأمر بناء indexes/MASTER_LEGAL_INDEX.csv وindexes/LAW_STATUS_INDEX.csv من مسارات الملفات تحت laws/, principles/, fiqh/, cases/, sources/, research/, schemas/ وingestion/. لا يحذف الملفات الأصلية ولا يعدل محتواها.

## التحقق دون كتابة

    python tools/rebuild_indexes.py --check
    python tests/test_indexes.py

يكتشف التحقق الفهارس القديمة، وتكرار المعرّفات أو المسارات، والمسارات التي لا تشير إلى ملفات موجودة.

## التحديث الآلي
يمكن تشغيل أداة إعادة البناء يدويًا بعد كل تحديث. أتمتة الإيداع إلى الفرع الرئيسي تعتمد على صلاحيات GitHub Actions وسياسة المستودع؛ لم أفعّل إيداعًا آليًا إلى main دون التحقق من إعدادات الصلاحيات.

## حدود قانونية
الفهرسة الآلية فهرسة لمسارات الملفات وبيانات وصفية مستنتجة من المسار، وليست تحققًا من صحة نص القانون أو تعديله أو نفاذه. تبقى حالة النفاذ unknown ما لم تُراجع وثيقة رسمية وتُسجل نتيجة التحقق. ولا تعد سجلات المبادئ القضائية سوابق موثقة قبل مراجعة أصل الحكم.
