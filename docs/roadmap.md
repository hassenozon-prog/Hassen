# خارطة استكمال المشروع

## مكتمل
- الهيكل الأساسي.
- سجل المصادر.
- مخططات السجلات.
- المرافعات والتنفيذ: نواة المواد.
- الإجراءات الجزائية: نواة المواد.
- الجرائم والعقوبات: نواة المواد.
- المبادئ القضائية: فهرس وسجلات أولية.
- القضايا والمسائل القانونية: قوالب.
- بروتوكول التحقق.

## المرحلة التالية
- استكمال النصوص الموحدة لكل قانون مع سجل التعديلات.
- إدخال القوانين اليمنية ذات الأولوية.
- توسيع مبادئ المحكمة العليا من المصادر المنشورة.
- بناء قاموس كلمات مفتاحية وروابط بين المواد.
- إضافة اختبارات تحقق آلية للروابط والحقول.
- مراجعة كل سجل قانوني قبل اعتباره «موثقًا بالكامل».

## معيار الاكتمال
لا يعد القانون مكتملًا لمجرد وجود ملف باسمه؛ بل عند توفر النص الموحد، التعديلات، المصدر، وفهرس المواد وحالة التحقق لكل مادة.
