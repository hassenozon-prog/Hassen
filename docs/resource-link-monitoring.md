# فحص روابط الموارد القانونية

يشغّل `python tools/check_resource_links.py --report /tmp/resource-link-check.csv` فحصًا مبدئيًا لروابط الموارد المحددة في السجلات.

- يجري الفحص على روابط عامة مسجلة فقط؛ ولا يحاول تسجيل الدخول أو تجاوز الحماية.
- تقرير `reachable` يعني أن طلب HTTP نجح، ولا يثبت صحة المحتوى أو جهة الإدارة أو الحجية القانونية.
- `check_failed` لا يعني أن الموقع مغلق؛ قد يكون السبب حظرًا آليًا أو تحويلًا أو مهلة أو حاجزًا جغرافيًا.
- يعيد GitHub Actions الفحص أسبوعيًا ويعرض نتيجته في سجل التنفيذ. لا يعدّل الفحص بيانات السجل تلقائيًا؛ تُراجع النتيجة بشريًا قبل تحديث `link_status` أو `last_checked`.
- الروابط الفارغة في دليل الدول تُترك فارغة إلى أن يُعثر على صفحة رسمية محددة؛ لا تُملأ بالتخمين.
