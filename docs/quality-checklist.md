# قائمة فحص الجودة

- [ ] القانون ورقمه وسنته صحيح.
- [ ] رقم المادة صحيح.
- [ ] النص مطابق للمصدر.
- [ ] التعديلات اللاحقة مفحوصة.
- [ ] المصدر محفوظ.
- [ ] الوقائع منفصلة عن الادعاءات.
- [ ] الأدلة محددة.
- [ ] التكييف مرتبط بعناصر النص.
- [ ] المبدأ القضائي له مصدر.
- [ ] لا توجد نسبة قضائية غير موثقة.
- [ ] البيانات الشخصية غير اللازمة مستبعدة.
- [ ] تاريخ التحقق مسجل.
