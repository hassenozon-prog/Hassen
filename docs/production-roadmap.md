# خارطة الانتقال للإنتاج

## مكتمل
- قاعدة المعرفة.
- محرك الاسترجاع المعجمي.
- الاسترجاع الهجين الأولي.
- بوابة التحقق.
- طبقة الاستدلال.
- طبقة الصياغة.
- محرك تحليل القضايا.
- API موحدة.
- اختبارات CI.

## الخطوات الإنتاجية التالية
1. ربط مصدر رسمي لكل سجل قانوني ومراجعة حالة النفاذ دورياً.
2. إضافة فهرس دلالي/متجهي بجانب البحث المعجمي.
3. إضافة مصادقة وRate limiting وCORS مضبوط عند نشر API.
4. بناء واجهة ويب فعلية فوق /query و/case.
5. إضافة سجل تدقيق Audit Log دون تخزين أسرار أو بيانات حساسة بلا ضرورة.
6. إضافة إدارة إصدارات للقوانين والتعديلات.
7. إضافة مجموعات اختبارات قانونية معيارية لكل مادة ومبدأ قضائي.
