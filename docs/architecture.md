# هندسة المشروع

## الطبقات
1. `laws/` — النصوص والتشريعات.
2. `sources/` — مصادر التحقق.
3. `principles/` — المبادئ القضائية والمسائل القانونية.
4. `cases/` — تمثيل القضايا.
5. `fiqh/` — المصادر الشرعية والفقهية.
6. `research/` — منهجية البحث والتحقق.
7. `schemas/` — نماذج البيانات.

## قاعدة الربط
كل سجل قانوني يجب أن يستطيع الرجوع إلى مصدره، وكل مبدأ قضائي إلى حكمه أو مجموعته، وكل تحليل إلى النصوص والأدلة التي يستند إليها.
