# خط الأنابيب الكامل

1. **Retrieval** — استرجاع النصوص ذات الصلة.
2. **Verification** — فحص التحقق والنفاذ.
3. **Reasoning** — تصنيف المسألة وبناء القواعد المدعومة.
4. **Drafting** — تحويل النتائج إلى مسودة قانونية يمنية.
5. **API** — تقديم كل النتائج في عقد موحد.

## قاعدة أمان مركزية

لا يجوز لطبقة الصياغة تجاوز بوابة التحقق أو إنشاء مصدر غير موجود.

## حالات العمل

- لا توجد مصادر: يعاد تحذير ولا تصدر مسودة نهائية.
- توجد مصادر غير متحققة فقط: تعرض للمراجعة.
- يوجد مصدر متحقق ونافذ: يمكن إنشاء مسودة أولية للمراجعة القانونية.
- وجود مصدر متحقق لا يعني أن الوقائع صحيحة؛ الوقائع تبقى مسؤولية المستخدم وملف القضية.

## التطوير اللاحق

يمكن استبدال lexical retrieval بفهرس متجهي أو هجين دون تغيير عقد الاستدلال والصياغة.
