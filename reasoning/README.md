# طبقة الاستدلال القانوني

تستقبل نتائج محرك الاسترجاع وتبني طبقة منظمة بين المصدر والجواب النهائي.

المبادئ:
- النص الموثق النافذ مقدم على غيره.
- لا يتحول الاستنتاج إلى حقيقة دون سند.
- تظل الوقائع منفصلة عن النصوص.
- لا ينسب مبدأ قضائي للمحكمة العليا دون مصدر موثق.
- النتائج غير المتحققة تظهر كتحذير ولا تستخدم كأساس وحيد.

المراحل:
1. تصنيف المسألة.
2. استخراج أرقام المواد والقوانين والقضايا.
3. ترتيب المصادر بحسب التحقق والنفاذ.
4. بناء propositions مدعومة بالمصادر.
5. إصدار تحذيرات التحقق.
6. تمرير الناتج إلى طبقة الصياغة النهائية.
