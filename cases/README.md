# قاعدة القضايا والنماذج القانونية

هذا القسم مخصص لتمثيل القضايا لأغراض البحث القانوني والتدريب، مع عدم إدخال بيانات شخصية أو سرية غير لازمة.

## بنية القضية
- الوقائع الثابتة.
- الإجراءات.
- الأدلة.
- المسائل القانونية.
- النصوص المنطبقة.
- التكييف القانوني.
- دفوع الخصوم.
- أسباب الحكم.
- أسباب الطعن.
- النتيجة.
- المصادر.

## ضابط مهم
يجب الفصل بين الوقائع المنقولة من الملف وبين التحليل القانوني. ولا يجوز تحويل فرضية أو ادعاء خصم إلى واقعة ثابتة.
