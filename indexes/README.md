# فهارس نبراس القانون — مستودع Hassen

## الغرض
هذا المجلد يضيف طبقة فهرسة قابلة للقراءة الآلية فوق ملفات المستودع الموجودة. أُنشئت الملفات الجديدة دون حذف أو استبدال أي ملف سابق.

## الملفات
- `MASTER_LEGAL_INDEX.csv`: فهرس بنيوي للملفات ذات الصلة بالتشريعات والقضاء والفقه والقضايا والمصادر والبحث ومخططات البيانات.
- `LAW_STATUS_INDEX.csv`: سجل أولي لحالة مجموعات التشريعات التي ظهرت في شجرة المستودع.

## قواعد مهمة
1. الفهرسة البنيوية لا تثبت صحة النص أو رسميته أو نفاذه.
2. `partially-verified (repository metadata only)` تعني أن وصف التحقق الجزئي نُقل من بيانات المشروع الموجودة، ولم يُعد التحقق المستقل من كل مادة في هذا التحديث.
3. `needs-verification` يعني عدم الاعتماد النهائي قبل التحقق.
4. `effective_status=unknown` يعني أن النفاذ وآخر التعديلات لم يتحققا في هذا التحديث.
5. تُحدّث هذه الفهارس بعد أي إضافة أو تعديل في ملفات التشريعات أو المبادئ أو المصادر.
6. لا تُدرج بيانات سرية أو معلومات شخصية في هذه الفهارس.

## ترتيب التحقق
MASTER_LEGAL_INDEX → LAW_STATUS_INDEX → المصدر القانوني الأصلي → تسجيل نتيجة التحقق وتاريخها.

## ملاحظة بشأن ملفات Excel
لم تظهر في شجرة الفرع `main` ملفات أصلية باسم `MASTER_LEGAL_INDEX.xlsx` أو `LAW_STATUS_INDEX.xlsx`. أُنشئت بدائل CSV جديدة دون الادعاء بأنها ملفات Excel الأصلية. يمكن إضافة نسخ XLSX لاحقًا إذا زُوّد المستودع بالملفين الأصليين أو أُنشئت نسخ Excel معتمدة من هذه الفهارس.
