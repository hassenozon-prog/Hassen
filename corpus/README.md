# Corpus القانوني اليمني

هذا المجلد مخصص للنصوص القانونية المتحققة، وليس لمقتطفات البحث.

كل سجل قانوني يجب أن يحدد:
- اسم القانون ورقمه وسنته.
- رقم المادة عند التقسيم إلى مواد.
- المصدر الرسمي.
- حالة التحقق.
- حالة النفاذ.
- التعديلات أو النصوص المستبدلة إن وجدت.

المصادر الرسمية الحالية تشمل فهرس قوانين وزارة العدل وخدمة النصوص القانونية.
