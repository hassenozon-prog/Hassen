# محرك الاسترجاع القانوني

محرك استرجاع خفيف يعمل دون مكتبات خارجية. يقرأ ملفات md/yml/yaml/json من المستودع، يطبع العربية، ويحسب ترتيباً أولياً يعتمد على تطابق المصطلحات القانونية وأرقام المواد والقوانين وحالة التحقق والنفاذ.

## الاستخدام

python retrieval/engine.py "دليل لم يطرح في الجلسة" --limit 8
python retrieval/engine.py "المادة 499 منازعة تنفيذ" --json

الناتج يتضمن context وsources ليكون قابلاً للتمرير إلى نموذج اللغة.

هذا محرك lexical retrieval أولي، وليس حكماً قانونياً ولا بديلاً عن التحقق من المصدر الرسمي والتعديلات.
