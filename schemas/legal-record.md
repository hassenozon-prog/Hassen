# مخطط سجل قانوني

لكل سجل قانوني يمكن اعتماد الحقول الآتية:

- id: معرف فريد.
- jurisdiction: نطاق الاختصاص، مثل اليمن.
- source_type: قانون أو لائحة أو قرار أو حكم أو مبدأ أو مرجع فقهي.
- title: اسم المصدر.
- law_number: رقم القانون إن وجد.
- year: السنة.
- article: رقم المادة إن كان المصدر تشريعياً.
- text: النص الموثق.
- source_url: رابط المصدر.
- source_authority: الجهة الرسمية أو الناشرة.
- verification_status: موثق أو يحتاج تحقق أو غير متحقق.
- amendments: التعديلات المرتبطة.
- related_records: السجلات المرتبطة.
- notes: ملاحظات بحثية.

## قاعدة مهمة
لا تتحول الملاحظات التحليلية إلى نص قانوني. يجب الفصل بين النص والتعليق والتحليل.
