# المادة (16) — الجرائم الجسيمة

**القانون:** الجرائم والعقوبات رقم (12) لسنة 1994م.

**النص:** الجرائم الجسيمة هي ما عوقب عليه بحد مطلقاً أو بالقصاص بالنفس أو بإبانة طرف أو أطراف، وكذلك كل جريمة يعزر عليها بالإعدام أو بالحبس مدة تزيد على ثلاث سنوات.
