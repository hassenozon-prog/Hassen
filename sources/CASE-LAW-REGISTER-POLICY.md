# سجل الأحكام القضائية — سياسة الإدخال

هذا الملف مُنشأ عمدًا بلا أحكام مدخلة؛ لا يجوز اختلاق رقم حكم أو تاريخ أو موضوع أو رابط أصلي.
أدخل الحكم فقط عند الوصول إلى نصه أو نشره الرسمي، وسجل المحكمة والدائرة والرقم والتاريخ والموضوع ورابط الأصل ورقم الصفحة/الفقرة وحالة التحقق.
الحكم المنقول في قاعدة تجارية أو منشور اجتماعي يبقى بحاجة إلى مطابقته مع الأصل الرسمي قبل الاستشهاد.
