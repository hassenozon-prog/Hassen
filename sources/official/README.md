# سجل المصادر الرسمية اليمنية

## الأولوية
يعتمد المشروع المصادر الرسمية اليمنية كلما كانت متاحة، مع تسجيل الجهة والرابط وحالة التحقق.

## مصادر رئيسية
- وزارة العدل وحقوق الإنسان اليمنية: بوابة القوانين والتشريعات والخدمات القضائية.
- النيابة العامة اليمنية: مجموعة التشريعات اليمنية.
- المحكمة العليا ومجلس القضاء الأعلى: الأحكام والقرارات والمبادئ المنشورة عند توفرها.
- المركز الوطني للمعلومات: قاعدة التشريعات والمعلومات الحكومية.

## قاعدة التوثيق
لا يكفي ذكر اسم الموقع؛ يجب حفظ عنوان المصدر وتاريخ التحقق والرابط، والتمييز بين النص الرسمي والشرح أو الدراسة.
